XmlObj, XmlObjOper, XmlAttrOper 세 클래스가 노출하는 API 목록과 각 API가 GetTarget()을 거쳐 위임되는지 직접 구현되는지 정리한 표

XmlObj
GetTarget() → this
operator() GetTarget 경유
operator[] 상속 GetTarget 경유
operator<< 상속 GetTarget 경유
operator=(char*/Obj*) 상속 GetTarget 경유
operator=(XmlObj&) 직접 부모에 위임
XmlObjOper
GetTarget() → ObjRoot
operator[] 상속 GetTarget 경유
operator<< / operator= 상속 GetTarget 경유
operator=(XmlObjOper&) 직접 rhs.GetTarget 필요
변환연산자 4종 직접 미구현 stub
XmlAttrOper
GetTarget() 없음 (독립)
operator=(char*/Str*) 직접 AttrRoot 직접
변환연산자 2종 직접 미구현 stub
AssignObjOper·AssignAttrOper 둘 다 상속 안 함
